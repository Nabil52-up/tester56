SISTEM PEMBAYARAN UANG PARKIR - JAVA

Isi:
- Main.java
- Kendaraan.java
- Motor.java
- Mobil.java
- Pembayaran.java
- PembayaranTunai.java
- JenisKendaraan.java
- TransaksiParkir.java

Cara menjalankan:
1. Ekstrak file ZIP.
2. Buka NetBeans dan buat project Java baru, atau masukkan semua file .java ke dalam source package project.
3. Pastikan semua file berada di package yang sama.
4. Jalankan Main.java.

Tarif contoh:
- Motor: Rp2.000 per jam
- Mobil: Rp5.000 per jam

Program ini memakai input jam penuh dari pengguna dan belum menyimpan data ke database.
